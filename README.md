# Разряд-Арена Bot

Telegram-бот для организации любительских турниров и команд по CS2, футболу, баскетболу и волейболу.

## Возможности

- Регистрация и профили игроков
- Команды: создание, набор, заявки, приглашения по ссылке
- Турниры: подача заявок, модерация, сетки, расписание матчей
- Два режима расписания турнира:
  - **Обычный** — у каждого матча своё время и место, напоминание за час
  - **Sequential (живая очередь)** — единое время старта, матчи играются один за другим, активный матч продвигается автоматически
- CS2 map veto / pick-ban с настраиваемым пулом карт (1–10) и форматом BO1/BO3/BO5
- Ручной ввод результатов и индивидуальной статистики игроков
- История матчей и персональная статистика по виду спорта
- Рейтинг команд и игроков (общий + сезонный, для CS2 ещё форматный 1×1 / 2×2 / 5×5)
- Live-посты рейтинга в Telegram-канале с автообновлением
- Реферальная система с начислениями за участие в турнирах и матчах
- Админ-панель: модерация, рассылки, управление сетками, ручные корректировки рейтинга
- Экспорт данных и PNG-сеток для статического сайта проекта

## Быстрый старт

```bash
git clone <repo>
cd razryadarena_bot
python -m venv .venv
.venv\Scripts\activate           # Windows
# source .venv/bin/activate       # Linux / macOS
pip install -r requirements.txt
cp .env.example .env              # и заполните значения
```

- `init_db()` сам выполнит миграции и создаст недостающие колонки/таблицы.

## Что важно знать

### Sequential-турнир

- Один общий старт `start_at_utc` и общая локация на весь турнир.
- Матчи играются строго по одному; активный матч помечается `queue_state='active'`.
- За час до старта команды получают broadcast, в момент старта — персональное сообщение со своей позицией в очереди.
- Каждой команде поддерживается живое queue-сообщение со статусом очереди. При смене этапа / появлении соперника / завершении их матча сообщение **пересылается заново**, чтобы не теряться за CS2 pick/ban.
- Матч за **3-е место играется перед финалом** (порядок: …полуфиналы → матч за 3-е место → финал).
- Если команда проиграла полуфинал, она видит «🥉 Вы ждёте матч за 3-е место» ещё до того, как этот матч физически создан в сетке.
- В уведомлении «⚔️ Назначен матч» строки «Время начала турнира» и «Перед вами N пар» показываются только для матчей первого раунда — для следующих этапов это излишне.
- Если админ забыл сгенерировать сетку, он получит предупреждение за час до старта и второе — после прошедшего времени старта.

### CS2 map veto

- Поддерживается пул карт от 1 до 10 уникальных карт.
- Последовательность ban/pick формируется динамически от формата матча и размера пула.
- Если капитан/команда не делает ход 5 минут, администратор может присудить тех.поражение через специальное уведомление с кнопками.
- Админ-капитан, запускающий veto из своей панели, не получает дублирующее сообщение в свой чат.

### Рейтинг

- Общий нестираемый рейтинг + сезонный рейтинг с архивом сезонов.
- Игроки и команды считаются раздельно.
- В CS2 дополнительно есть форматный рейтинг (1×1 / 2×2 / 5×5).
- Командные очки — после каждого матча, игроковые турнирные начисления — при завершении турнира.
- Тех.победы засчитывают командные очки и игроковые турнирные очки победителю.
- Реферальные бонусы идут только в общий и сезонный общий рейтинг, форматный CS2 не трогают.
- Live-посты в канале обновляются автоматически после изменений.

### Реферальная система

- Атрибуция засчитывается только новому пользователю; перепривязка существующего игнорируется.
- Self-referral запрещён.
- Начисления:
  - +2 владельцу ссылки, когда реферал попал в одобренную заявку турнира того же спорта,
  - +3 владельцу ссылки, когда реферал сыграл первый нетехнический матч,
  - +2 самому рефералу за первый нетехнический матч.

### Синхронизация сайта

При включённом `SITE_SYNC_ENABLED` бот собирает `tournaments.json`, `ratings.json`, `matches.json`, кладёт PNG-сетки в `temp/brackets/` и выгружает всё по FTP. Триггеры выгрузки: старт воркера, по таймеру, после ключевых изменений турниров, рейтинга, сеток и сохранения результатов матчей.

## Уведомления и фоновые задачи

`main.py` запускает `reminder_worker`, который раз в минуту:

- отправляет напоминания за час до матчей в обычном режиме,
- шлёт уведомления о завершении регистрации турнира,
- управляет жизненным циклом sequential-турниров (broadcast за 1ч, авто-старт, продвижение очереди),
- запускает CS2 veto, у которых подошло время.

Часть админских уведомлений — «tracked-action»: если один администратор обработал ситуацию, у остальных это уведомление автоматически становится неактуальным.

## База данных

SQLite. Путь:

- если есть директория `/app/data` — `/app/data/razryad_arena.db`,
- иначе `./razryad_arena.db`.

Все миграции выполняются автоматически в `init_db()` при запуске. Схема включает пользователей, команды и составы, турниры и заявки, сетки, CS2 veto-сессии, рейтинги, реферальные ссылки и события, статистику по картам и видам спорта.

## Локализация и кодировка

Интерфейс на русском. Все исходные файлы хранятся в UTF-8.

## Проверка после изменений

Минимум:

```bash
python -m compileall -q .
```

При изменениях в турнирах/сетках/матчах/рейтинге дополнительно стоит пройти:

- бот стартует без ошибок,
- открываются регистрация, команды, карточка турнира,
- генерируется и обновляется сетка,
- сохраняется результат матча,
- рейтинг обновляется,
- при `SITE_SYNC_ENABLED=true` в логах виден `Starting site sync`.
